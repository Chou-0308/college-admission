# Findings
The key-takeaways list: a bold `accent` label on the left, one or two short paragraphs on the right, rows divided by hairlines under a 2px `ink` top rule.

Static rendition of `.find` in `media/index.html`.

**Markup:** `div.find > ul > li` → `span.k` (label) + `div` of `p`s. First paragraph is `finding-lead` (1rem).

- Label column is 150px; below 640px label stacks above text.
- Use `<b>` (highlighter on `hl`) for the number or phrase to remember; `<b class="warn">` (`em`) for a caveat.
- One idea per row; lead with the number.
