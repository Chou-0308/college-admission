# JumpLinks
A row of pill links that jump to sections on a long page.

From `.jump` in `assets/style.css`.

- 0.82rem, `paper` pill with `line` border, `radius-pill`; hover turns border and text `accent`; focus 2px `accent` outline.
- Targets are `section[id]` (scroll-margin-top 16px). Keep labels to a few words.
