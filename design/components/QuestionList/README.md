# QuestionList
A list of official or quoted questions, each in its own `paper` box with a small source line above.

Static rendition of `.qlist` (used in `media/prep.html`).

- `li`: `paper`, 1px `line`, 12px × 14px padding, 0.9rem.
- `span.src`: 0.76rem `muted`, letter-spacing .02em — university · kind of source.
- Quote the question as published; don't paraphrase.
