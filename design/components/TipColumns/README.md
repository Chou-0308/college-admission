# TipColumns
Two side-by-side lists of advice, each under an `h3` on a 2px `ink` rule with a `muted` count.

Static rendition of `.cols` (used in `media/prep.html`).

- Two equal columns, 28px gap; one column below 720px.
- Lists at 0.92rem with 8px row gap; `span.cnt` shows how many reviews mentioned it.
- Quote real phrasing in “ ”; keep each item to one line where possible.
